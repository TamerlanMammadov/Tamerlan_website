# Tamerlan Mammadov — Personal Portfolio

A personal portfolio built with Next.js, React, TypeScript, and CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build for production

```bash
npm run build
npm start
```

## Included

- Responsive portfolio layout
- About, skills, projects, experience, education, training, and contact sections
- Resume PDF in `public/`
- Existing GitHub and LinkedIn links preserved
